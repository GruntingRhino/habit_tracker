# Static Ad Concepts

## Global spec
- 1080x1920 for vertical placements, 1080x1350 for feed if cropped later
- Native social look, not brochure design
- Short headline, one supporting line, one CTA
- Real UI only if the layout includes a screen
- No fake proof

## 1) Instagram feed static
- **Name:** Every Monday I Start Over
- **Platform:** Instagram feed
- **Funnel stage:** cold
- **Objective:** thumb-stop and installs
- **Hyperframe:** self-recognition hook
- **Target pain:** restarting habits every Monday
- **Hook:** “Every Monday, I start over.”
- **Layout:** creator portrait on dark background, bold hook at top, small app wordmark at bottom
- **Copy:** “One habit. One reminder. One system.”
- **CTA:** Start with one habit today.
- **Required UI assets:** none for the concept version; optional real dashboard inset for the final build
- **A/B variant:** “I keep restarting my habits.”
- **Success metric:** thumb-stop rate, CTR
- **Compliance check:** no fake analytics or testimonials

## 2) Story / Reels vertical static
- **Name:** Pick One Habit
- **Platform:** Instagram Stories / Reels static
- **Funnel stage:** cold to warm
- **Objective:** challenge offer
- **Hyperframe:** one-habit challenge
- **Target pain:** too many goals, no consistency
- **Hook:** “Pick one habit for 7 days.”
- **Layout:** full-bleed dark background, oversized hook, checklist-style subcopy, CTA button style at the bottom
- **Copy:** “Do not add five habits. Add one.”
- **CTA:** Track one habit for 7 days.
- **Required UI assets:** habits page screenshot if the final version wants proof
- **A/B variant:** “Set your first reminder.”
- **Success metric:** swipe-up / click-through, activation rate
- **Compliance check:** no made-up progress claims

## 3) Retargeting static
- **Name:** You Do Not Need Another Complicated App
- **Platform:** Meta retargeting
- **Funnel stage:** warm / retarget
- **Objective:** objection crusher
- **Hyperframe:** objection crusher
- **Target pain:** users who bounced because the app seemed like too much work
- **Hook:** “You do not need another complicated productivity app.”
- **Layout:** left-aligned hook, three short bullets, small CTA block
- **Copy bullets:**
  - One habit
  - One reminder
  - Visible progress
- **CTA:** Try LiveImproved.
- **Required UI assets:** dashboard / habits / reminder screenshots if used
- **A/B variant:** swap “complicated productivity app” for “five productivity apps”
- **Success metric:** CTR, activated user rate
- **Compliance check:** no fake feature list

## 4) App-screen-first static
- **Name:** Today Screen
- **Platform:** Meta, Instagram feed, Stories
- **Funnel stage:** warm / high intent
- **Objective:** real UI proof
- **Hyperframe:** progress / streak visual
- **Target pain:** users want a visible system, not vague motivation
- **Hook:** “Make consistency visible.”
- **Layout:** full-bleed real dashboard screenshot with a small caption strip and CTA footer
- **Copy:** “One habit makes the day visible.”
- **CTA:** Make consistency visible.
- **Required UI assets:** dashboard / streak / analytics screenshot from the real app
- **A/B variant:** swap dashboard for add-habit screen if the proof angle needs simplicity
- **Success metric:** CTR, first habit created, day-7 completion
- **Compliance check:** the screenshot must be real app UI only
