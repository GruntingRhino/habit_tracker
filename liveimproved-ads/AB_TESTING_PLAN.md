# A/B Testing Plan

## Primary goal
Optimize for activated users, not just installs.

## Activation definition
- first habit created
- reminder set
- first completion logged

## Core hypotheses
- creator / UGC hooks will beat polished product intros on cold traffic
- real UI will outperform lifestyle-only proof on warm traffic
- a single clear CTA will outperform multi-CTA confusion
- progress / streak screens will outperform abstract claims when the user is already warm
- shorter ads will win on top-of-funnel, while slightly longer demos will win on retargeting

## What to test
- Hook
- Creator vs product-first framing
- UI timing: early vs late
- Proof type: dashboard vs analytics vs add-habit flow
- CTA text
- Challenge framing vs objection-crusher framing
- Lifestyle scene vs UI-first scene

## Metric stack
- thumb-stop rate
- 3-second hold
- 25% watch
- 50% watch
- CTR
- install rate
- first habit created
- day-7 completion
- cost per activated user

## Test matrix suggestion
- Cold traffic: 7s hook, 15s UGC, 14s challenge
- Warm traffic: 24s demo, 10s progress ad, 12s objection crusher
- Proof present vs no-proof versions
- CTA variants: “Start with one habit today” vs “Track one habit for 7 days”

## Decision rule
- keep the winning hook
- keep the highest-activation CTA
- keep the real UI timing that produces the best hold and activation rate
- cut any ad that needs fake proof or over-explains the product
